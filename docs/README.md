# 文档索引

> 本目录按「项目生命周期」组织：从需求到交付逐个阶段。仓库根的 [README](../README.md) 仍是对外门面（结果与口径以它为准）；接口契约以《接口文档》为准。
> 房规：**同一事实只写一遍** —— 有载体的挂靠，不复制；每份只回答自己那一问。

## 怎么保持

- 新读者从 00 进：导读只指路、不复制，改它不改别处。
- 每轮扩展翻一遍清单：改需求动 01，改设计动 02，加能力动 03，改接口动 04，加题集动 05。
- 新增/替换法规（语料）时动 01 §5 的来源与收录口径表。
- 数字不在这里、也不在 01–06 里重复维护：效果与实测口径只在 README。
