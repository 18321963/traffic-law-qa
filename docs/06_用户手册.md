# 用户手册 · 交通法规问答 Agent

> 写给**用界面提问的人**：怎么问、怎么读答案与引用、哪些做不到。前提是界面已经在部署里跑着（宿主 `:3000`）；从零安装与部署见 [README](../README.md)「快速开始」与[运维手册](../deploy/运维手册.md)。
> 同一个服务的命令行与 HTTP 入口在 §7 只给指路；接口签名细节在[接口文档](04_接口文档.md)§3。

## 1. 界面地图

| 区域 | 是什么 |
|---|---|
| 顶栏 | 标题、数据来源徽标（直连服务 / 示例数据）、状态条、设置开关 |
| 左栏 | 会话列表：「新会话」、切换、清掉本地记录；带 `session_id` 的会话有跨轮记忆 |
| 中栏 | 问答区：欢迎语与一轮轮的「问」—— 问题 → 草稿 → 答复 → 依据 |
| 右栏 | 处理轨迹（这一轮走到哪了）与材料台账 |
| 底栏 | 输入框、提问 / 停止、流式 / 一次性切换、会话与材料的小字状态 |

## 2. 怎么问

- 一个具体问题一问，例如「机动车闯红灯一次记多少分？」；回车发送，Shift+回车换行。输入框下面有几条示例问题，点一下直接填入。
- **涉及具体地区会先问**：服务停下来给你一张「按哪里的规定作答？」卡片 —— 按它识别到的地区 / 只按全国法 / 手填别的地区 / 先不恢复直接问新问题。卡片会列出库里已有的地方性法规。
- **追问带记忆**：同一条会话里接着问，会带上前文上下文；点「新会话」开的将是不带记忆的一条。
- **随时可以停**：提问中转圈时按「停止」，这一轮不再等收尾，已收到的文字会保留并注明「已取消」。
- **带上材料问**：在右栏材料里勾选后，本次提问会带上这些材料（见 §4）。

## 3. 怎么读答案

### 3.1 两段式：先草稿，后权威版

先流式出现的是**草稿**（标「草稿」），复核完成后**整篇替换成权威版本**。如果替换前后不一致，界面会提示，并可展开「复核前的草稿」对照。

复核没过的轮次，服务**不给结论**：给的是降级答复与未经复核确认的候选法条，标注「复核未过」，供人工复审。

### 3.2 复核标签怎么读

| 标签 | 含义 |
|---|---|
| 已复核 | 复核分过了阈值；详情里给「X/Y 条依据在答案里有支撑」 |
| 复核未过 | 复核给了否定结论，按降级答复看，别当权威版 |
| 本次未复核 / 本次未打分 | 复核没跑完 / 没有可打分的判据（注里说明原因） |
| 未复核 | 答案里没有引用依据，没有可判的据 |

**复核分不是正确性保证** —— 它看的是引用标得干不干净（哪条结论后面挂着哪条法条），分数高也可能结论错。把它当闸，不当裁判。

### 3.3 依据与引用

- 正文里的 `[依据N]`（库内法条）、`[材料N]`（本次会话材料）、`[时效N]`（联网时效信息，默认不启用）都是**可点**的：点了会滚到下面对应条目并高亮。
- 答复下方是「答案引用的依据」：条名、原文摘录、（有的话）相关度分。
- 再往下可展开「本次检索的命中（含未被引用的）」，末尾注明本次用了哪些通道（稠密 / BM25）—— 未被引用的命中也值得看，能发现答案漏没漏。
- 没有依据的答案会被界面明说「答案没有引用依据」。

## 4. 材料（右栏）

支持 `.docx` / `.md` / `.txt` / `.pdf`，两种入库方式：

| 方式 | 谁可见 | 引用标 | 撤销 |
|---|---|---|---|
| 会话材料 | 只在这条会话里可检索 | `[材料N]` | 台账里「撤下」即可 |
| 永久入库 | 写进知识库，**重建索引之后**才可检索 | `[依据N]` | 手工移文件并重建索引 |

台账每条显示 会话 / 永久 与状态；勾选框决定这条会话的提问是否带上它。

## 5. 会话、状态条与设置

- **会话**只是本机浏览器的记录，不会同步到服务；「×」清掉即本地消失。挂着地区澄清的会话如果直接问新问题，那次澄清即作废（之后恢复会得到 409，重新提问即可）。
- **状态条**（顶栏）：绿灯＝服务正常（附检索通道态）；黄灯＝降级 —— 常见三种：权重指纹未知、生成层不可用（没有模型密钥，答问会拒答）、通道降级为纯 BM25；降级**不等于不可用**，它会照常回答并说明。红灯＝知识库不可达或探活失败。点开有详情（通道、重排、法条 / 行数、装配耗时等）和「立刻探活」。
- **设置**（联调 / 运维向，普通提问不用动）：数据来源（内置示例数据 / 直连服务）、服务基地址、X-API-Key、召回条数 `top_k`、流式 / 一次性。改动只存在本机浏览器。示例数据源下另有「问答演练场景」「状态条演练场景」两个下拉 —— 那是在不连服务时演练各种成功 / 失败 / 降级的样子用的。

## 6. 做不到什么（照着说清楚）

- 只答**收录范围内**的交通法规：全国法规 + 少量地方性法规（清单见[需求规格说明书](01_需求规格说明书.md)§5）。库外的地方规定答不了。
- 输出是法规原文的**检索与引用整理，不构成法律意见**。
- **默认不联网**：工具面没有网页搜索，`[时效N]` 引用只在启用网搜时才会出现。
- 「已复核」只说明引用卫生过了闸，不担保结论正确（§3.2）。
- 出错会明确报出来（限流要等窗口、服务未就绪、鉴权未通过等），**不会静默给错答案**。
- 落地前请对照法规原文与现行有效版本 —— 这里是辅助检索的起点，不是终点。

## 7. 不用界面也能问

- 命令行：`python -m agent_service "问题"`（加 `--trace` 看决策链）；只要检索：`python -m rag_service "问题" --search`。
- HTTP：`POST /qa`（一次问答）· `POST /qa/stream`（流式）· `POST /qa/resume`（澄清恢复）· `POST /documents`（材料）—— 签名与示例在[接口文档](04_接口文档.md)§3；起服务的步骤在 README「快速开始」。
